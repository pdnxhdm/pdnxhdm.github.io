# Лабораторная работа № 2

## Моделирование случайного потока и системы обслуживания

Интерактивный учебный сайт по лабораторной работе. Он состоит из четырёх самостоятельных экспериментов: поток Пуассона, система обслуживания, зависимые потоки и выбор стратегии пропускной способности (вариант А). Все расчёты выполняются в браузере; серверная часть, сборка и установка пакетов не нужны.

## Запуск и публикация

### Локально

Откройте `index.html` в браузере либо запустите в корне проекта простой сервер:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).

### GitHub Pages

1. Загрузите содержимое репозитория в ветку `main`.
2. На GitHub откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и каталог `/ (root)`, затем нажмите **Save**.
4. Дождитесь успешного workflow Pages. Адрес сайта будет показан в настройках Pages; для репозитория `pdnxhdm.github.io` это `https://pdnxhdm.github.io/`.

## 1. Поток Пуассона

Пусть (X_n) — число заявок за один временной интервал. При интенсивности (lambda):

\[
X_n\sim\operatorname{Pois}(\lambda),\qquad
P(X_n=k)=e^{-\lambda}\frac{\lambda^k}{k!},\quad k=0,1,2,\ldots
\]

Теоретические характеристики:

\[
\mathsf E[X]=\lambda,\qquad
\mathsf D[X]=\lambda,\qquad
\mathsf E[X^2]=\mathsf D[X]+(\mathsf E[X])^2=\lambda+\lambda^2.
\]

В интерфейсе задаются интенсивность и размер выборки (N\in\{10^2,10^3,10^4,10^5\}). Для выборки (X_1,\ldots,X_N) выводятся:

\[
\overline X=\frac1N\sum_{i=1}^N X_i,\qquad
\widehat{\mathsf D}(X)=\frac1N\sum_{i=1}^N(X_i-\overline X)^2,\qquad
\overline{X^2}=\frac1N\sum_{i=1}^N X_i^2.
\]

Таблица сопоставляет теорию и эксперимент, показывает абсолютное отклонение и его относительный процент; цвет помогает быстро оценить расхождение. Увеличение (N) обычно уменьшает статистические колебания, но конечная выборка не обязана точно совпадать с теоретическими значениями. Для распределения Пуассона математическое ожидание и дисперсия равны одной и той же интенсивности.

**Замечание о составе сайта.** В текущем интерфейсе показана таблица моментов; гистограмма частот не реализована. Если преподаватель требует графическое сравнение эмпирических частот (n_k/N) и теоретических (P(X=k)), его следует добавить в отчёт отдельно.

## 2. Система массового обслуживания

За шаг приходит (X_n\sim\operatorname{Pois}(\lambda)) заявок, а система обслуживает не более (c). Число заявок в очереди после обслуживания:

\[
Q_0=0,\qquad Q_n=\max\bigl(0,Q_{n-1}+X_n-c\bigr).
\]

Коэффициент нагрузки:

\[
\rho=\frac{\lambda}{c}.
\]

На сайте мощность фиксирована (c=50), а ползунок задаёт (0\le\rho\le2), поэтому интенсивность потока вычисляется как (\lambda=50\rho). Объём эксперимента выбирается кнопками (10^2,10^3,10^4,10^5). График (Q_n) строится слева направо за несколько секунд по постоянной временной шкале; горизонтальная линия показывает выбранный критический уровень (L).

Для каждого режима оцениваются:

\[
\overline Q=\frac1N\sum_{n=1}^N Q_n,\qquad
Q_{\max}=\max_{1\le n\le N}Q_n,\qquad
\widehat P(Q>0)=\frac1N\sum_{n=1}^N\mathbf1\{Q_n>0\}.
\]

Число обслуженных заявок за шаг равно (B_n=\min(Q_{n-1}+X_n,c)), а средняя доля занятой мощности:

\[
\overline U=\frac1N\sum_{n=1}^N\frac{B_n}{c},\qquad
\widehat P(Q>L)=\frac1N\sum_{n=1}^N\mathbf1\{Q_n>L\}.
\]

Ожидаемое поведение: при (\rho<1) очередь обычно не имеет устойчивого линейного роста, но случайные всплески возможны; при нагрузке около единицы она становится чувствительна к флуктуациям; при (\rho>1) средний приток превосходит мощность и очередь в среднем растёт. Высокая загрузка сама по себе не гарантирует хорошее качество обслуживания — важны также ожидание и вероятность превышения (L).

## 3. Два зависимых потока

Пусть (A,B,C) независимы и имеют распределения Пуассона с интенсивностями (\lambda_A,\lambda_B,\lambda_C). Общий поток (C) входит в оба наблюдаемых потока:

\[
X=A+C,\qquad Y=B+C.
\]

По свойствам суммы независимых пуассоновских величин:

\[
\mathsf E[X]=\lambda_A+\lambda_C,\qquad
\mathsf E[Y]=\lambda_B+\lambda_C,
\]
\[
\mathsf D[X]=\lambda_A+\lambda_C,\qquad
\mathsf D[Y]=\lambda_B+\lambda_C.
\]

Общий компонент создаёт ковариацию:

\[
\operatorname{Cov}(X,Y)=\lambda_C,\qquad
\operatorname{Corr}(X,Y)=
\frac{\lambda_C}{\sqrt{(\lambda_A+\lambda_C)(\lambda_B+\lambda_C)}}.
\]

Сайт генерирует пары ((X,Y)), строит диаграмму рассеяния и оценивает выборочную ковариацию и корреляцию с делителем (N). Когда (\lambda_C=0), потоки независимы и теоретическая ковариация равна нулю. При росте общего компонента связь усиливается; корреляция приближается к единице, если общий поток доминирует над индивидуальными компонентами. Ковариация выражена в квадрате единиц счёта, корреляция безразмерна и лежит между (-1) и (1).

## 4. Сравнение стратегий управления (вариант А)

Система получает пуассоновский поток с интенсивностью \(\lambda\). Базовая мощность равна (c); при включении дополнительного канала мощность увеличивается на \(\Delta c\). Пусть (I_n\in\{0,1\}) показывает, включён ли дополнительный канал на шаге (n). Тогда:

\[
c_n=c+\Delta c\,I_n,\qquad
Q_n=\max(0,Q_{n-1}+X_n-c_n).
\]

Сопоставляются три правила:

* **S1:** канал всегда выключен, (I_n=0).
* **S2:** канал включён постоянно, (I_n=1).
* **S3(q):** канал включается, когда очередь перед шагом достигает порога: (I_n=\mathbf1\{Q_{n-1}\ge q\}).

Стоимость дополнительного канала — (b), стоимость единицы очереди за шаг — (a). Вариант А фиксирует интенсивность, мощности и (a), меняя относительную цену \(\gamma=b/a\). Усреднённая стоимость:

\[
\overline C_N=\frac1N\sum_{n=1}^N(aQ_n+bI_n),\qquad
q^*(\gamma)=\arg\min_q\overline C_N^{S3(q)}.
\]

Одновременно для S1, S2 и оптимальной S3 оцениваются средняя стоимость, средняя очередь, максимум очереди, доли \(Q>0\), \(Q>L\) и включения канала \(I=1\). Для каждой стратегии отображается временной график очереди и уровень (L); ниже показана функция (q^*(\gamma)) и сводная таблица. Все стратегии, разделившие минимальную стоимость в таблице, выделяются.

В вычислительной реализации сайта фиксированы \(\lambda=20,c=20,\Delta c=10,a=5\), (N=10\,000); (\gamma\) меняется от 0.1 до 50, а (b=a\gamma). Порог ищется перебором неотрицательных целых значений. **Согласование формулы с текущим кодом:** стоимость ожидания внутри симулятора начисляется по очереди до обслуживания, то есть фактически использует (Q_{n-1}), хотя формулировка задания записывает (Q_n). Это сохранено при структурном рефакторинге, чтобы не менять численные результаты работающего сайта; при подготовке отчёта следует использовать и явно оговорить принятую конвенцию.

При малом (\gamma) дополнительная мощность относительно дешева и раннее включение может окупаться снижением ожидания. По мере роста цены канала выгодным становится более высокий порог, а при достаточно большой цене дополнительный канал используется редко или стратегия без него оказывается дешевле. Точное поведение и границы режимов зависят от параметров и конечной случайной выборки; график (q^*(\gamma)) показывает результат эксперимента.

## Общие выводы для отчёта

1. С увеличением объёма выборки оценки характеристик потока обычно стабилизируются около теоретических значений, хотя случайная ошибка не исчезает полностью.
2. Для пуассоновского потока среднее и дисперсия равны \(\lambda\); второй момент равен \(\lambda+\lambda^2\).
3. Устойчивость очереди зависит от соотношения интенсивности потока и мощности обслуживания. Перегрузка проявляется ростом очереди, а близость к предельной загрузке повышает влияние случайных всплесков.
4. Общая пуассоновская составляющая порождает зависимость между потоками: ковариация равна её интенсивности.
5. Выбор пороговой стратегии балансирует цену ожидания и стоимость дополнительной мощности. Универсально лучшего правила нет: оптимум меняется при изменении относительной цены \(\gamma\).
6. Моделирование иллюстрирует теоретические зависимости, но не заменяет вывод формул и обсуждение статистической погрешности в отчёте.
