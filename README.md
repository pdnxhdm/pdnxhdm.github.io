# Queue Lab

Интерактивный статический сайт для лабораторной работы «Моделирование случайного потока и системы обслуживания». Сайт не использует backend, сборщик или внешние библиотеки: достаточно открыть `index.html` или разместить файлы на GitHub Pages.

## Что внутри

- **01 Поток Пуассона** — гистограмма эмпирических частот и теоретических вероятностей, среднее, дисперсия и второй момент.
- **02 Система обслуживания** — дискретная рекурсия `Q(n+1) = max(0, Q(n) + X(n+1) - c)`, график очереди и метрики нагрузки.
- **03 Зависимые потоки** — модель `X = A + C`, `Y = B + C`, scatter plot, ковариация и корреляция.
- **04 Стратегии мощности** — сравнение S1, S2 и S3(q), функция стоимости `hQ + kI(extra) + pI(overload)` и поиск `q*`.

## Структура

```text
index.html   разметка страницы
styles.css   адаптивные стили и визуальная система
app.js       симуляции и canvas-графики
README.md    инструкция
```

## Запуск локально

Откройте `index.html` двойным кликом. Для локального сервера можно выполнить `python3 -m http.server 8000` в этой папке и открыть `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `app.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Нажмите **Save** и дождитесь появления адреса сайта в этом же разделе.

Публикация и push не выполнялись автоматически.
